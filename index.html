REGION-BASED IMAGE ANALYSIS
01WHAT IT DOES

Quadtree segmentation recursively splits an image into four regions when a region is not homogeneous. Similar neighboring regions are then merged to reduce unnecessary fragmentation.

ALGORITHM

The process, step by step.

01

Upload the terrain image

The selected image is resized to a square processing canvas so the quadtree can recursively divide it into four equal quadrants.

IMAGE
02

Test for homogeneity

Sample pixels in each region and calculate mean intensity and variance.

03

Split non-uniform regions

If variance is above the threshold, divide the region into four child regions and continue recursively.

04

Merge compatible neighbors

Leaf regions sharing an edge are merged when their mean intensity and terrain class are sufficiently similar.

A + B → AB
05

Assign terrain classes

Each final region is classified using its average RGB characteristics.

DATA STRUCTURE

A tree that mirrors
the terrain.

Every split creates four child nodes. This hierarchical structure concentrates computation around areas where terrain changes and keeps uniform areas coarse.

T(n) ≈ 4T(n/4) + O(n)

The actual cost depends on the homogeneity test, image size, and implementation.

ABCD
Each node = one terrain region
WHY IT MATTERS

Useful where terrain
is spatially diverse.

Quadtree-based segmentation is useful when large parts of an image are uniform while boundaries contain complex detail.
